# 🎬 Produza um Filme

Jogo multiplayer onde amigos criam um filme juntos!

## Sobre o Jogo

**Produza um Filme** é um jogo casual para 2 a 4 jogadores onde cada pessoa tem um papel na criação de uma pequena animação:

- 🎬 **Diretor** - Cria a ideia da cena
- 🎨 **Animador** - Desenha a animação quadro a quadro
- 📝 **Roteirista** - Escreve as falas baseado na animação
- 🎙️ **Dublador** - Grava a voz dos personagens

O resultado é um pequeno filme criado pelo grupo!

## Tecnologias

- HTML + CSS + JavaScript
- Firebase Realtime Database (salas temporárias)
- GitHub Pages (hospedagem)

## Como jogar

1. Acesse o site
2. Crie uma sala ou entre com um código
3. Escolha seu nome e personagem
4. Aguarde os amigos na sala
5. Escolha seu cargo
6. Faça sua parte na produção
7. Assista ao filme final!

1. Clone o repositório
